# Feature Specification: F151 - Theme Store and Appearance Customization

## 1. Feature Identification
* **Feature ID**: `F151`
* **Feature Name**: Themes, Pure Black OLED Mode & Custom Palette
* **Domain**: Personalization
* **Evidence Standard**: `[CODE-CONFIRMED]` via REA JADX / `CustomThemeActivity` / `preferences_theme.xml`

---

## 2. Functional Description
Provides system-wide visual styling controls:
* **Standard Themes**: Classic Blue, Forest Green, Sunset Orange, Sakura Pink, Violet, Graphite.
* **Dark Mode**: System Follow, Dark Gray, and Pure Black OLED Mode (true `#000000` background for battery conservation).
* **City Themes (Pro)**: Stylized illustrative theme packs (London, Paris, Tokyo, New York) with custom illustrations on empty states.
* **Custom Hex Color Picker (Pro)**: Freeform primary accent color selection.
